## robber-master

References: `approved-art-style.png`

```text
Create one friendly cartoon robber antagonist in the approved cleaner-cartoon style. Use the same round-head/stick-limb construction and outline weight as Supa Dude, but a light-gray head, simple dark eye mask, small dark cap and no cape. Compact recognizable silhouette, no weapon, no text. Side-facing neutral pose, arms and legs visibly separated, full figure with padding on a uniform green chroma background. Save as robber-master and register as a separate AutoSprite V3 character. Face right so the game can mirror the sprite for pursuit. Keep the same canvas scale and ground anchor across all robber animations.
```
