# SupaDude verification map

Start a dedicated server and fresh tab with [the verification skill](../SKILL.md). Default QA settings use Medium boss difficulty, two robbers at 50%, and three at 90%. No account or seed data is required.

Use current AX handles for forms, keyboard shortcuts for gameplay, and fresh screenshots for canvas controls. Capture each action and its result under `artifacts/verification/<run-id>/`. Reopen changed settings for a second view. Report missing preconditions and skipped entry points explicitly. A practice fight does not prove normal course entry.
